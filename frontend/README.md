# Devis BTP — frontend

Angular 21 single-page application of Devis BTP (Angular Material, Signals stores, ngx-translate).

See the [root README](../README.md) for the project overview, installation, environment
variables, testing and production build. Quick reference from this folder:

```bash
npm ci                      # install
npm start                   # dev server on http://localhost:4200 (API expected on :8000)
npm test -- --watch=false   # unit tests (Vitest)
npx ng build --configuration production   # bundle in dist/frontend/browser
```
